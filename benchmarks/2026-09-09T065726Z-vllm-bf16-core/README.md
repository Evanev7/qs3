Pinned 35B BF16 vLLM graph run on sp10. The included script, image digest,
software versions and GPU/driver metadata reproduce the workload. The first
two prefill runs warm compilation and execution; the following five are measured.
Decode has four warmups and 256 measured forwards, contexts 4100 through 4356.

`8fdb3ca77a5d0ac3`, generated by repeating the exact 102-token base IDs. This is
a synthetic context-length workload, not independent language-quality data.
