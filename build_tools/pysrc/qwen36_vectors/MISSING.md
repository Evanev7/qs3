# Missing Coverage Checklist

This file tracks the correctness vectors that should exist before the qs3
Qwen3.6 runtime is trusted against the vendored vLLM semantics.

## Implemented foundation vectors

- Norms: Gemma RMSNorm and fused residual RMSNorm using raw nonzero weights.
  vLLM uses effective `weight + 1`, and the artifacts include standard-RMSNorm
  comparison tensors plus mismatch metadata. Generated by
  `qwen36-vectors generate-norms`.
- Full-attention primitives: packed per-head `[q, output_gate]` extraction, q/k
  Gemma RMSNorm, partial RoPE over 64 of 256 lanes, and sigmoid output gate.
- Full-attention block: six rows with real hidden/head dimensions covering
  input Gemma RMSNorm, Q/K/V projections, packed Q/gate split, q/k norm, partial
  RoPE, causal GQA attention, output gate, O projection, residual add, and
  post-attention Gemma RMSNorm.
- One full-attention decoder-layer slice: runs the private harness from the
  full-attention block input through attention output projection, then
  post-attention MoE/shared expert, residual add, and final next-layer Gemma
  RMSNorm. It uses real hidden size, GQA shape, 256 experts, and top-8 routing,
  but a synthetic MoE/shared-expert intermediate width of 8.
- Model logits: one public `ModelRunner::run` path with a full-attention layer,
  post-attention MoE/shared expert, prompt length 4, page size 4, one decode
  step at position 4, tiny vocab logits slices, and exact greedy ids. It uses
  real hidden/GQA shape, 256 experts, top-8 routing, and synthetic
  MoE/shared-expert intermediate width 8.
- MoE/shared expert: top-8 over 256 experts, top-k renormalization, routed MoE
  output, shared expert path, and final combine with standalone tiny hidden and
  intermediate width 8 vectors.
- GDN post-conv prep: causal conv width 4, q/k L2 normalization, beta/decay
  materialization, gated RMSNorm, and prefill recurrent output/final-state
  oracles for the qs3 raw-q/k normalized-inside-recurrence path, plus an
  integrated CUDA prefill/decode state-evolution vector across continued conv,
  post-conv prep, and recurrence.
- GDN decode continuation: two post-prefill decode recurrence steps per existing
  GDN case, seeded from the BF16 prefill final state and alternating read/write
  state slots.
- GDN decoder-layer slice: six rows with real hidden/GDN dimensions covering the
  private model harness from `execute_gdn_layer` through GDN output projection
  into `scratch.attn_proj`, then post-attention MoE/shared expert, residual add,
  and next-layer Gemma RMSNorm. It keeps 256 experts and top-8 routing with a
  synthetic MoE/shared-expert intermediate width of 8.

## Constraints

- Keep the generator independent from the future safetensors loader.
- Use deterministic synthetic weights with nonzero, signed, nonuniform patterns.
- Store BF16 values as raw `u16` bit patterns or document every BF16 rounding
  boundary explicitly.
- Keep vectors small, but use the actual qs3 Qwen3.6 dimensions where kernels
  require them.
